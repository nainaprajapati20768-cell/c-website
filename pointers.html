Pointer in C Programming

Question 1: Write a program in which a pointer should point to the array and through pointer we will fill the locations of the array by assigning values from the user and print the array.

View Solution

C Program:

#include 

int main()
{
    int a[5], *p, i;

    p = a;

    printf("Enter 5 numbers:\n");

    for(i = 0; i < 5; i++)
    {
        scanf("%d", p+i);
    }

    printf("Array values are:\n");

    for(i = 0; i < 5; i++)
    {
        printf("%d ", *(p+i));
    }

    return 0;
}

Output:

Enter 5 numbers:
10 20 30 40 50

Array values are:
10 20 30 40 50

Question 2: Write the program in which we are having 2D array of 2 by 3. Insert the values through pointer and print the values.

View Solution

C Program:

#include 

int main()
{
    int a[2][3], *p, i;

    p = &a[0][0];

    printf("Enter 6 numbers:\n");

    for(i = 0; i < 6; i++)
    {
        scanf("%d", p+i);
    }

    printf("Array values are:\n");

    for(i = 0; i < 6; i++)
    {
        printf("%d ", *(p+i));
    }

    return 0;
}

Output:

Enter 6 numbers:
1 2 3 4 5 6

Array values are:
1 2 3 4 5 6
