Nested Loops

1. Write a program print the pattern on the screen i.e. ?

View Solution
Solution

C Program

#include 

int main()
{
    int i, j;

    i = 1;

    while(i <= 3)
    {
        j = 1;

        while(j <= 5)
        {
            printf("1");
            j++;
        }

        printf("\n");
        i++;
    }

    return 0;
}

Output

11111
11111
11111
